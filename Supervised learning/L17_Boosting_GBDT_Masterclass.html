Boosting: what we already know

Bagging: many trees are trained largely independently and combined. Boosting: trees are dependent; each new learner is trained to improve the current ensemble.

Do not think “100 trees each solve the original problem.” Think: one model built as a sequence of corrections.

GBDT = Gradient Boosting + Decision Trees

PartQuestion it answers
Gradient BoostingWhat should the next learner learn? → use the loss gradient.
Decision TreeHow do we represent that correction? → partition feature space into regions/leaves.
\[ F_m(x)=F_{m-1}(x)+\eta f_m(x) \]

\(F\) is the current model score, \(f_m\) is the new tree correction, and \(\eta\) is the learning rate.

03 · regression

Step 0 — initial prediction: why is it the mean?

Before any tree exists, force the model to make one constant prediction \(c\) for every row.

\[ L_i=\frac12(y_i-c)^2 \]

The best constant is the one that minimises total training loss:

\[ c^*=\arg\min_c\sum_{i=1}^{n}\frac12(y_i-c)^2 \]
Derivation — every step

1. Differentiate with respect to the thing we are choosing: \(c\).

\[ \frac{d}{dc}\left[\sum_i\frac12(y_i-c)^2\right] \]
\[ =\sum_i\frac12\cdot2(y_i-c)(-1) \]
\[ =\sum_i(c-y_i) \]

2. At the minimum, derivative = 0.

\[ \sum_i(c-y_i)=0 \]
\[ nc-\sum_i y_i=0 \]
\[ \boxed{c=\frac1n\sum_i y_i=\bar y} \]
Conclusion: the initial prediction is the mean because the mean is the constant that minimises total squared error.

For our six rows:

\[ F_0=\frac{15+18+25+30+45+50}{6}=30.5 \]

Every row starts at \(30.5\).

Do not memorise “GBDT starts with mean.” Memorise the deeper rule: the initial model is the constant that minimises the chosen loss. The mean follows specifically from squared loss.

Derive residual from the loss

Start with the loss, not the residual:

\[ L(y,F)=\frac12(y-F)^2 \]

Differentiate with respect to the current model output \(F\):

\[ \frac{\partial L}{\partial F} =\frac12\cdot2(y-F)(-1) =F-y \]

The gradient points in the direction of increasing loss. To reduce loss, move in the opposite direction:

\[ r=-\frac{\partial L}{\partial F} =-(F-y) =\boxed{y-F} \]
For squared loss, negative gradient = ordinary residual. That is why the next regression tree can be trained on residuals.

General rule: pseudo-residual

\[ \boxed{r_{im}=-\left.\frac{\partial L(y_i,F(x_i))}{\partial F(x_i)}\right|_{F=F_{m-1}(x_i)}} \]

For other losses, the pseudo-residual need not equal \(y-F\). It is the loss-specific direction in which the current model should move.

How does the tree find a split?

The boosting algorithm has already decided the target for the tree: the pseudo-residual. The regression-tree machinery now finds regions where these correction targets are different.

Why the split criterion becomes SSE

For a candidate region \(S\), one leaf can only give one constant correction. The best constant is the mean pseudo-residual:

\[ \bar r_S=\frac1{|S|}\sum_{i\in S}r_i \]
\[ SSE(S)=\sum_{i\in S}(r_i-\bar r_S)^2 \]

For a candidate split:

\[ SSE_{\text{split}}=SSE(S_L)+SSE(S_R) \]
\[ \boxed{\text{Improvement}=SSE(S)-[SSE(S_L)+SSE(S_R)]} \]
Meaning: the split is useful when two specialised correction values fit the pseudo-residuals better than one parent correction.

06 · regression leaf

How does the leaf predict? Derive the mean residual

Suppose a leaf \(R_j\) contains several observations. The leaf cannot assign a different correction to every row. It must choose one constant \(\gamma_j\).

\[ J(\gamma_j)=\sum_{i\in R_j}\frac12[y_i-(F_i+\gamma_j)]^2 \]
Complete leaf derivation

1. Differentiate with respect to \(\gamma_j\).

\[ \frac{dJ}{d\gamma_j} =\sum_{i\in R_j}(F_i+\gamma_j-y_i) \]

2. Set derivative to zero.

\[ \sum_{i\in R_j}(F_i+\gamma_j-y_i)=0 \]

3. Rearrange.

\[ \sum_{i\in R_j}\gamma_j =\sum_{i\in R_j}(y_i-F_i) \]
\[ |R_j|\gamma_j=\sum_{i\in R_j}(y_i-F_i) \]
\[ \boxed{\gamma_j=\frac1{|R_j|}\sum_{i\in R_j}(y_i-F_i)} =\boxed{\text{mean residual in the leaf}} \]
Intuition: the leaf asks, “I can only make one correction for everyone here. Which single number minimises their total squared error?” The answer is the mean residual.

07 · regression

Learning rate: why not take the whole correction?

The tree proposes a correction. Boosting deliberately shrinks it:

\[ \boxed{F_m(x)=F_{m-1}(x)+\eta f_m(x)} \]

For a particular leaf:

\[ \boxed{F_m(x)=F_{m-1}(x)+\eta\gamma_j} \]
\(\eta\)Tree proposes +10Actual contribution
1.0+10+10
0.5+10+5
0.1+10+1
Purpose: smaller \(\eta\) makes the model learn more gradually. It often requires more trees, but each tree has less power to make an aggressive mistake.
Do not confuse them: \(\eta\) is a global shrinkage factor. Leaf values can be different in every leaf and every tree.

09 · classification

Now classification: what changes?

Suppose \(y\in\{0,1\}\) and we want probability of class 1. The model builds an additive raw score \(F\), then sigmoid converts it to probability.

\[ F(x)\in(-\infty,\infty) \qquad p(x)=\sigma(F)=\frac1{1+e^{-F}} \]
Why raw score? Corrections can be positive or negative and can be added freely. Probabilities are constrained to \([0,1]\).
Initial prediction — derive the positive-class rate

Assume the model initially predicts the same probability \(p\) for every row. Binary log loss is:

\[ J(p)=-\sum_i[y_i\log p+(1-y_i)\log(1-p)] \]

Differentiate with respect to \(p\):

\[ \frac{dJ}{dp} =-\sum_i\left(\frac{y_i}{p}-\frac{1-y_i}{1-p}\right) \]

Set it to zero:

\[ \frac{n_+}{p}=\frac{n_-}{1-p} \]
\[ n_+(1-p)=n_-p \]
\[ n_+=p(n_++n_-)=pn \]
\[ \boxed{p_0=\frac{n_+}{n}=\bar y} \]

Convert this probability into raw score:

\[ \boxed{F_0=\log\left(\frac{p_0}{1-p_0}\right)} \]
Example: 3 positives out of 6 → \(p_0=0.5\), so \(F_0=\log(1)=0\).
10 · classification

Where does the pseudo-residual \(y-p\) come from?

For one observation:

\[ L=-[y\log p+(1-y)\log(1-p)] \]

The model variable is \(F\), but loss is written using \(p\). Therefore use the chain rule:

\[ \frac{\partial L}{\partial F} = \frac{\partial L}{\partial p} \frac{\partial p}{\partial F} \]
Step 1 — derivative of log loss with respect to p
\[ \frac{\partial L}{\partial p} = -\frac{y}{p} + \frac{1-y}{1-p} \]
Step 2 — derivative of sigmoid with respect to F
\[ p=\frac1{1+e^{-F}} \]
\[ \boxed{\frac{\partial p}{\partial F}=p(1-p)} \]
Step 3 — chain rule multiplication
\[ \frac{\partial L}{\partial F} = \left(-\frac{y}{p}+\frac{1-y}{1-p}\right)p(1-p) \]
\[ =-y(1-p)+p(1-y) \]
\[ =-y+yp+p-py \]
\[ \boxed{\frac{\partial L}{\partial F}=p-y} \]

Gradient points uphill, so the correction direction is the negative gradient:

\[ \boxed{r=-g=y-p} \]
That is the entire reason \(y-p\) appears. It is the negative derivative of log loss with respect to the raw model score.

11 · classification tree

How should each classification tree split?

Do not mix these two ideas

ModelTarget given to treeSplit concept
Ordinary classification tree0/1 labelsGini / entropy / related label criteria
Classic GBDTcontinuous negative-gradient targetregression-tree style fitting of the gradient target
Important: Gini is not the thing being derived here. We are following the boosting loss. The tree is learning a continuous correction signal, using regression-tree-style fitting on that signal — not label-based impurity.

Why do sums appear?

Total loss over a leaf is the sum of row losses:

\[ L_{\text{leaf}}=\sum_{i\in R}L_i \]

Therefore derivatives add:

\[ G=\sum_{i\in R}g_i,\qquad H=\sum_{i\in R}h_i \]
G = total directional pressure. H = total curvature.
12 · first principles

Before \(-G/H\): what is Taylor series?

Taylor expansion approximates a function near a point using its derivatives.

First derivative

tells the local slope / direction.

Second derivative

tells how quickly the slope changes — the local curvature.

From function → local approximation

Suppose current raw score is \(F\), and we add a correction \(w\).

\[ L(F+w)\approx L(F)+L'(F)w+\frac12L''(F)w^2 \]

Use ML notation:

\[ \boxed{L(F+w)\approx L(F)+gw+\frac12hw^2} \]
SymbolMeaning
\(F\)current model score
\(w\)new leaf correction
\(g=\partial L/\partial F\)slope / direction
\(h=\partial^2L/\partial F^2\)curvature
Geometric intuition: gradient says which way downhill is; Hessian says how sharply the loss bends. The second-order step uses both.
13 · classification / second-order leaf

Derive the leaf value: where exactly does \(-G/H\) come from?

Take one leaf \(R\). Every row in that leaf gets the same correction \(w\).

\[ \sum_{i\in R}L_i(F_i+w) \approx \sum_{i\in R}\left[L_i+g_iw+\frac12h_iw^2\right] \]

The \(\sum L_i\) term does not depend on \(w\), so it does not affect the minimising \(w\).

Step 1 — collect first-order terms
\[ \sum_{i\in R}g_iw=w\sum_{i\in R}g_i \]
\[ \boxed{G=\sum_{i\in R}g_i} \]
\[ \text{first-order term}=Gw \]
Step 2 — collect second-order terms
\[ \sum_{i\in R}\frac12h_iw^2 = \frac12w^2\sum_{i\in R}h_i \]
\[ \boxed{H=\sum_{i\in R}h_i} \]
\[ \text{second-order term}=\frac12Hw^2 \]
Step 3 — the leaf optimisation problem
\[ \boxed{J(w)=Gw+\frac12Hw^2} \]

Now we have a simple quadratic. Find its minimum.

Step 4 — differentiate with respect to w
\[ \frac{dJ}{dw}=G+Hw \]

At the minimum:

\[ G+Hw=0 \]
\[ Hw=-G \]
\[ \boxed{w^*=-\frac{G}{H}} \]
This is the origin of \(-G/H\). It is the minimiser of the second-order Taylor approximation of the loss for a leaf.

Numerator \(G\)

Total gradient pressure. It tells how strongly the leaf wants the score to move.

Denominator \(H\)

Total curvature. It tells how strongly the local loss resists a large step.

14 · classification

For binary log loss: derive gradient and Hessian

We already obtained:

\[ \boxed{g=\frac{\partial L}{\partial F}=p-y} \]

Differentiate once more:

\[ h=\frac{\partial^2L}{\partial F^2} = \frac{\partial(p-y)}{\partial F} \]

Since \(y\) is fixed:

\[ \boxed{h=\frac{\partial p}{\partial F}=p(1-p)} \]

So inside a leaf:

\[ \boxed{G=\sum_{i\in R}(p_i-y_i)} \]
\[ \boxed{H=\sum_{i\in R}p_i(1-p_i)} \]
\[ \boxed{ w^* = -\frac{\sum_i(p_i-y_i)} {\sum_i p_i(1-p_i)} = \frac{\sum_i(y_i-p_i)} {\sum_i p_i(1-p_i)} } \]
The numerator is the total negative-gradient signal. The denominator adjusts the step according to curvature.

18 · underfit / overfit

Underfitting vs overfitting: reason first, tune second

Underfitting

Training poor + validation poor.

The model lacks capacity or is constrained too aggressively.

  • increase depth / leaves carefully
  • increase rounds
  • reduce overly large minimum-leaf constraints
  • reduce excessive regularisation

Overfitting

Training keeps improving while validation worsens or plateaus.

The ensemble is learning increasingly specific patterns that do not generalise.

  • shallower trees / fewer leaves
  • larger minimum leaf constraints
  • lower learning rate
  • early stopping / fewer effective rounds
  • subsampling

Read the training/validation pattern

ObservationLikely reasonAction
Train bad, validation badtoo little capacityincrease capacity or rounds carefully
Train excellent, validation poortoo much variancereduce complexity, add constraints, early stop
Both improve slowlysteps may be too smallmore rounds / tune learning rate
Train improves rapidly, validation peaks earlyaggressive corrections / too many stageslower learning rate + early stopping
Do not simply minimise training loss. The goal is good performance on unseen data.
19 · tuning strategy

A practical tuning order: capacity → step size → stages → randomness

1
Set tree complexity.
Choose reasonable depth / leaves and minimum leaf size.
2
Choose learning rate.
Smaller \(\eta\) makes each correction more conservative.
3
Increase number of trees.
Smaller corrections generally need more stages.
4
Use validation / early stopping.
Let unseen-data performance decide when enough trees have been added.
5
Add stochasticity if needed.
Subsampling rows or limiting feature candidates can reduce variance.
\[ \boxed{\text{learning rate}\downarrow+\text{number of trees}\uparrow\text{ is a common search pattern}} \]
It is a search pattern, not a law. Always validate empirically.
20 · final algorithm

GBDT algorithm: end-to-end without skipping steps

Regression — squared-error GBDT

1
Choose loss: \(L(y,F)=\frac12(y-F)^2\).
2
Initialise: \(F_0=\arg\min_c\sum_iL(y_i,c)=\bar y\).
3
Compute pseudo-residuals: \(r_i=y_i-F_{m-1}(x_i)\).
4
Fit regression tree: features \(X\) → pseudo-residuals \(r\); choose splits that reduce pseudo-target SSE.
5
Leaf correction: mean residual in each leaf.
6
Shrink and update: \(F_m=F_{m-1}+\eta f_m\).
7
Repeat: recompute residuals from the new \(F_m\) and train the next tree.

Binary classification — log-loss GBDT

1
Choose loss: \(L=-[y\log p+(1-y)\log(1-p)]\), \(p=\sigma(F)\).
2
Initialise: \(p_0=\bar y\), \(F_0=\log[p_0/(1-p_0)]\).
3
Compute gradient: \(g_i=p_i-y_i\); negative gradient \(r_i=y_i-p_i\).
4
Grow tree: fit a regression tree to the negative-gradient target, same as regression GBDT — find regions where correction signals differ.
5
Second-order leaf update: \(G_j=\sum g_i,\ H_j=\sum h_i,\ h_i=p_i(1-p_i)\), then \(w_j^*=-G_j/H_j\) in the unregularised Taylor/Newton form.
6
Update raw score: \(F_m=F_{m-1}+\eta f_m\), then \(p_m=\sigma(F_m)\).
7
Repeat.
21 · final memory map

GBDT: everything in one page

1

Start simple

Find the constant prediction that minimises the chosen loss.

2

Find direction

Use the negative gradient: “which way should the current model move?”

3

Make regions

A tree partitions feature space into regions needing similar corrections.

4

Choose correction

Squared regression → mean residual. Second-order form → \(-G/H\).

5

Shrink it

Learning rate \(\eta\) controls how much of the tree enters the ensemble.

6

Repeat

Every new tree sees the errors / loss geometry left by the current ensemble.

Equations worth remembering
\[ \boxed{F_m=F_{m-1}+\eta f_m} \]
\[ \boxed{r_i=-\frac{\partial L}{\partial F_i}} \]
\[ \boxed{\text{Squared regression: }r_i=y_i-F_i} \]
\[ \boxed{\text{Binary log loss: }r_i=y_i-p_i} \]
\[ \boxed{p_i=\sigma(F_i)=\frac1{1+e^{-F_i}}} \]
\[ \boxed{g_i=p_i-y_i,\qquad h_i=p_i(1-p_i)} \]
\[ \boxed{G_j=\sum_{i\in R_j}g_i,\qquad H_j=\sum_{i\in R_j}h_i} \]
\[ \boxed{w_j^*=-\frac{G_j}{H_j}} \]

The one-sentence mental model

GBDT repeatedly builds a tree that learns how the current model should change, turns that into region-specific corrections, shrinks the correction, adds it to the ensemble, and repeats.
Final distinction to never mix up: \(y-F\) is the residual for squared-error regression because negative gradient equals residual. \(y-p\) is the negative gradient for binary log loss. \(-G/H\) is a second-order leaf update obtained by minimising a Taylor approximation.
